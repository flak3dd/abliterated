# LLM Fine-Tuning — Instruction Dataset

A cleaned, single-schema supervised fine-tuning (SFT) dataset covering LLM
fine-tuning mechanics, PEFT, alignment, data curation, evaluation, inference
optimization, defensive-security knowledge, and agentic/tool-use patterns.

## Dataset card

- **Format:** OpenAI/ChatML `messages` schema, one JSON object per line (JSONL).
  Every record is `{"messages": [ {role, content}, … ]}`; tool-use records add a
  top-level `"tools"` array plus `assistant.tool_calls` and `role:"tool"` turns.
- **System prompts:** one per domain (see each section) so the model learns a
  consistent persona without per-example drift.
- **Loss masking (training convention):** compute loss on `assistant` turns only;
  mask prompt/`system`/`tool` tokens to `-100`. Keep `eos` in the labels; mask pad.

### Curation applied to the source

| Issue in source | Action |
|---|---|
| ~3–5× near-duplicate Q&A (warmup, LoRA rank, cosine, QLoRA, gradient clipping, …) | Collapsed to one canonical entry each |
| Three mixed schemas (`instruction/response`, `messages`, `function/args/note`) | Normalized all to `messages` |
| `{"function","args","note"}` config blocks (not input→output pairs) | **Dropped** — not valid SFT examples; the facts they encoded are already covered by canonical Q&A |
| Truncated / nested-malformed JSON (duplicated "default credentials", cut-off `search_codebase`, unterminated `slugify`) | Dropped the unrecoverable ones; kept the two complete, valid variants |
| Incorrect answers | Corrected (see below) |

### Technical corrections made while rewriting

- **"Ablation" ≠ pruning.** The source answer conflated them. Split into three
  distinct meanings; for this project "abliteration" = orthogonalizing the refusal
  direction in activation space, which does **not** remove weights.
- **LoRA `alpha`.** Effective scale is `alpha/r`; common practice is `alpha = r` or
  `2r`, not the source's "`alpha = r/2`."
- **Temperature scaling** is an inference/distillation concept, not a standard SFT
  training knob (softmax temperature is not tuned during next-token cross-entropy).
