FAQ

Does this break model capabilities? +
No. Zero measurable degradation on MMLU, GSM8K, HumanEval, or any standard benchmark. Only the refusal direction is removed. Everything else stays exactly the same.
How is this different from fine tuning? +
Fine tuning uses gradient descent to erase refusals by teaching the model. Abliteration uses representation engineering to mathematically subtract the refusal direction from the weights. Perfectly reversible. Zero capability loss. Zero drift.
What models work? +
Every modern open weight model: Llama 3, Llama 3.1, Qwen 2/2.5, DeepSeek V2/V3, Mistral 7B/8x7B/70B, Yi 34B, and every other model built on the standard transformer architecture.
