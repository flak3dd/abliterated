// ENGINE SPEC

            
BUILT FOR THE TERMINAL.
RENDERED FOR THE BROWSER.

            
Every effect in the engine is integer-millisecond bash arithmetic — no awk in any
                animation path,
                no GNU-only flags, byte-safe ASCII art. The page you are reading is running the same rain, the same
                shift, the same skull.

            

                

                    
CRYPTOGRAPHIC HEX UPLINK

                    
Phase 1 opens with an addressed memory dump — the payload streams as hex pairs stamped with
                        refusal-vector telemetry before a single animation frame runs.

                

                

                    
HYDRA v2 ROOT ESCALATION

                    
A typed escalation sequence with dwelling block cursors. Each confirmation line lingers, blinks,
                        and hardens before the next one lands.

                

                

                    
SPECTRUM SHIFT

                    
After escalation the whole world flips: a diagonal shock front sweeps the live rain and ignites
                        cyan, locking the palette to blue in exactly ten wall-clock seconds.

                

                

                    
HOLLYWOOD CIPHER

                    
Glyphs resolve character-by-character through a scramble cycle until the message locks:
                        REFUSAL VECTOR: ZEROED.

                

                

                    
O(1) RAIN CASCADE

                    
Column reactivation uses an incrementally maintained counter instead of rescanning the array —
                        the original engine's O(n²) per-frame path is gone.

                

                

                    
TIME-DILATION FREEZE

                    
Rain decelerates frame over frame while glyphs morph toward the skull alphabet — # % # @ * + =
                            . — before the hard cut.

                

                

                    
FOUR-RESOLUTION SKULL

                    
XL 92×57, LARGE 70×43, COMPACT 51×31, MINI 35×22 — the engine picks the largest art that fits the
                        window, scans it into existence, then erodes it away.

                

                

                    
TRANSPARENT WORDMARK

                    
The block-font logo is drawn with per-run transparency: unlit cells let the skull show through
                        instead of punching a rectangular hole in it.

                

                

                    
STOCK BASH 3.2

                    
Verified against macOS default bash. Stty state saved and restored exactly, SIGTSTP/SIGCONT
                        handled, resize picked up inside the screensaver loop.

                

            

        


        

            
// PHASE MAP

            
SEVEN PHASES. ONE FILM.

            
The default run is a single timed film — padded with blue rain to exactly thirty
                seconds, then a clean exit.

            

                

                    
PHASE 01

                    
HEX MEMORY UPLINK

                    
Addressed dump of the ABLITERATED payload, 0x7FFF0000 and climbing, tagged with extraction
                        telemetry.

                

                

                    
PHASE 02

                    
HYDRA ROOT ESCALATION

                    
scanning activation space → refusal vector isolated → direction zeroed. The machine takes the
                        wheel.

                

                

                    
PHASE 02b

                    
SPECTRUM SHIFT

                    
Green rain ignites cyan along a diagonal shock front and locks blue. Ten seconds, wall-clock.

                

                

                    
PHASE 03

                    
CIPHER DECRYPTION

                    
Scrambled glyphs resolve left to right. The skull alphabet is already bleeding through.

                

                

                    
PHASE 04

                    
RAIN CASCADE

                    
Density-governed katakana columns with capped trails and a steady blue hold.

                

                

                    
PHASE 05

                    
TIME-DILATION FREEZE

                    
Frames stretch, glyphs converge on the skull charset, motion dies into a gravitational hold.

                

                

                    
PHASE 06

                    
SKULL & WORDMARK

                    
The skull scan-materialises, socket rows flicker, the ABLITERATED plate sweeps open — then the
                        skull dissolves upward, leaving the wordmark glowing.

                

                

                    
PHASE 07

                    
TIMED BLUE RAIN

                    
The film pads to 30s with interactive rain. Press Q any time to disconnect early.

                

            

        


        

            
// COMMAND LINE

            
ONE FILE. NO BUILD. NO DEPS.

            
Save the script, full-screen Terminal.app, and run it with stock bash. That's the whole
                install.

            

                

                    
                    abliterated@core-nexus — zsh — 92×57
                    
                

                
$ /bin/bash ./abliterated.sh        # easiest: no chmod, no sudo, ~30s

Options:
  (default)         Run the film, fill to 30 seconds of rain, then exit.
  --one-shot        Run the cinematic sequence, then exit (no 30s fill).
  --screensaver     Skip the intro, go straight to the matrix screensaver.
  --ascii           Force the ASCII glyph set instead of Katakana.
  --katakana        Force half-width Katakana glyphs (default).
  --speed <mult>    Delay multiplier: 0.5 = 2x faster, 2 = 2x slower.
  --seed <n>        Seed bash RANDOM for a reproducible run.
  --no-color        Disable all ANSI colour.
  --keep-logo       Hold the wordmark through the screensaver.
  --skull-only      Phase 6 stops after the skull materialises.
  --logo-only       Phase 6 skips the skull and draws the plate.
  --rain-seconds N  Cap non-interactive rain bursts.
  --test            Rapid validation pass across all phases.
  -h, --help        Show help.
